- **Sound:** output through the Windows default device or the one chosen in SYSTEM > AUDIO (WASAPI shared mode; a few tens of milliseconds of delay for engine sounds); **ASIO** is in the separate ASIO zip only (an ASIO driver is normally used by one program at a time: if Ableton has it, Verdandi says so and uses WASAPI on the same hardware). Input from the sound card (MIC) and the system's own sound (SYS, WASAPI loopback) is in; the input is always OFF at the start. The RME and other real hardware results are the owner's checks (`docs/port/HARDWARE-CHECKLIST.md`).
- **In this build:** MIDI devices (WinMM), loopMIDI cables, OSC input, MIDI clock in and out, Ableton Link, monome grids over their serial ports (real arcs are untested), maiden (editor, script catalog, consoles) with git and busybox, mods, the plug-in packs (sc3-plugins, mi-UGens).
- **Not in this build yet:** importing files and folders into dust (dropping them on the window, Import files/folder in the right-click menu and the file dialog all say so: copy the files into the dust folder yourself, Show dust folder in the menu opens it); the virtual grid, arc and keyboard windows (the GRID, ARC and KEYS buttons do nothing); crow and other serial devices; USB game controllers; the manual (the MANUAL button says so); announcing the OSC service by Bonjour; NamAmp; an installer.
- **Screenshots and GIFs** go to the Windows Pictures folder, in a folder `Verdandi` (the dust folder if Pictures cannot be found).
- **Unsigned:** Windows may warn about an unknown program (More info, Run anyway). Windows Firewall may ask about `norns.exe` and `sclang.exe`; Cancel is fine, nothing needs the network.
- **Tested by the workflow:** the program starts headless on a Windows runner (no sound card there: null audio and the fallback are exercised), ten start/restart cycles with a script copying files between them, the crash handler, maiden and its consoles, the plug-ins in the real server, the Linux-side unit tests. **Not tested by the workflow:** the real window, menus and file drops, keyboard feel, real sound output and latency, a device unplugged while running, antivirus reactions. Those are the owner's checks (`docs/port/HARDWARE-CHECKLIST.md`).
- **If something crashes:** send `%USERPROFILE%\Verdandi\logs\norns.log`, `launcher.log`, `sclang.log` and everything in `logs\crash\`.
