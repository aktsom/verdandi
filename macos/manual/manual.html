1. what this is

norns is a sound computer by monome: a small box running Lua scripts, a SuperCollider audio engine and the softcut sample looper, with a 128×64 screen, three keys and three encoders. this port runs the same software natively on macOS. the window shows the device: the screen behind its bezel, the keys and encoders where they sit on a norns, played with the mouse or the computer keyboard. the community scripts run unchanged.

everything that makes a norns a norns is here: matron (scripts, screen, devices), crone and softcut (audio routing, loopers, tape), SuperCollider with the sc3-plugins, and maiden (the web editor with the script catalog). in addition the app installs an AUv3 plugin that puts norns into a DAW track.

2. installing

requirements: a Mac with Apple silicon (M1 or later), macOS 13 Ventura or newer.

  1. open norns.dmg and drag norns onto Applications.
  2. the app is not notarized by Apple (it is ad-hoc signed, without a developer identity). the first time, right-click norns.app → Open and confirm. if macOS still refuses, open System Settings → Privacy & Security and click Open Anyway.
  3. when norns asks for the microphone, allow it: that is the audio input for softcut, tape and engines. (you can change it later under Privacy & Security → Microphone.)

3. first start

norns starts its audio server, the SuperCollider engine and maiden, then opens the norns window. the first start takes a little longer: macOS checks the bundled libraries once.

your norns lives in the folder ~/norns in your home folder, laid out like /home/we on the device:

pathcontents
~/norns/dust/codeinstalled scripts
~/norns/dust/audiosamples, tape recordings (audio/tape)
~/norns/dust/datascript data, PSETs, system settings
~/norns/nornsa link into the app (the norns core); do not edit
~/norns/*.loglogs, see files and logs

to stop norns, close its window, quit it from the Dock, or choose SLEEP in the norns menu. only one norns runs at a time.

4. controls

keyboard

while the norns window is in front, the keyboard is the norns hardware:

keysnorns
1 2 3K1 K2 K3 (held while you hold the key, so K1 + turn works)
Q / WE1 left / right
A / SE2 left / right (in scripts also ↑ / ↓)
Z / XE3 left / right (in scripts also ← / →)
with ⇧5 steps at once; holding a key keeps turning
F1–F4, F5menu pages MIX, TAPE, HOME, PARAMS; F5 toggles the menu
F6opens or closes the virtual grid

this works wherever nothing else wants the keys. when a text entry is open (naming a file, searching), you type. scripts that use the keyboard themselves (live coding, keyboard instruments, about 14 of the 350 catalog scripts) get the keys; there, hold ⌥ (Option) with the keys above, or press ⌥Esc to force hardware keys on or off (the window title then reads norns · keys).

mouse

the keys and knobs in the window are the controls:

  • keys: click K1, K2 or K3. the key stays down while you hold the mouse button.
  • knobs: drag a knob up or right to turn it clockwise, down or left for counter-clockwise. or scroll over it. scrolling anywhere else turns the nearest knob. hold ⇧ while dragging for fine steps, ⌘ for fast ones.
  • for K1 + turn, hold 1 on the keyboard and turn a knob with the mouse.

the keys and knobs in the window always show what norns receives, also from the keyboard.

the buttons above the device

the real norns does not have these; they save trips through the menu:

buttondoes
MIX TAPE HOME PARAMSopens that menu page (its light shows the page you are on). click the lit one to go back to the script.
GRIDopens or closes the virtual grid (also F6), see grid.
MAIDENopens maiden in your browser.
MANUALopens the documentation of the script that is running (from the script catalog), or this manual.

window

the window can be resized and keeps the shape of the device; the screen is always drawn with sharp pixels.

5. audio

norns starts with the Mac's default input and output (System Settings → Sound) at 48 kHz with a 256-frame buffer (about 5 ms). to use an audio interface, another sample rate or a smaller buffer, go to SYSTEM → AUDIO:

  • E2 picks a line, E3 changes it: INPUT, OUTPUT (an interface or default), RATE (44.1 to 96 kHz), BUFFER (64 to 1024 frames, with the latency next to it).
  • go to APPLY and press K3: norns restarts its audio with the new setting, which is kept for the next start.
  • if the setting does not work (say the interface cannot do that rate), norns goes back to the defaults and the AUDIO page says so. an interface that is unplugged is replaced by the Mac's default device.

a mono microphone (like the built-in one) feeds both norns inputs. levels, monitoring, reverb and compressor are in the norns MIX menu, as on the device.

6. maiden and the script catalog

maiden is norns' web editor. with norns running, open http://127.0.0.1:5000/maiden in your browser.

  • project manager (the box icon): browse the community catalog, install and update scripts. installed scripts appear in the norns SELECT menu.
  • editor: edit everything in dust.
  • REPL: the matron (Lua) and SuperCollider consoles; errors from scripts show up here.

unlike on the device, maiden and the consoles only answer on this Mac (127.0.0.1), not on your network: the consoles can run any code.

7. scripts

scripts run unchanged. the port takes care of what differs from the device:

  • scripts see the usual /home/we/dust/… paths; norns maps them to ~/norns.
  • the sc3-plugins (Decimator, MoogLadder, Greyhole, …) are built in.
  • require "cjson" uses the built-in JSON library.
  • shell commands find the same GNU tools as on the device.

scripts that bring compiled Linux programs or Linux-only UGens, or that install software with apt, can fail in those parts; everything else in them still works. an engine that fails to load blocks later engine loads until you restart norns (as on the device).

new engines are compiled when norns starts: after installing a script with its own engine, restart norns (or use SYSTEM → RESTART in the menu).

8. MIDI, grid, arc, crow, gamepads

  • MIDI: class-compliant USB MIDI devices and network/IAC ports appear in SYSTEM → DEVICES → MIDI. norns also creates a virtual port norns that other apps (a DAW) can send to and receive from.
  • grid and arc: plug them in; no serialosc needed.
  • no grid? the GRID button (or F6) opens a virtual 16×8 grid in its own window. norns and the scripts see it as a real grid (in SYSTEM → DEVICES it is virtual grid). click a key to press it, drag across keys to play them in turn, right-click (or ctrl-click) to hold a key down, for chords; right-click again to let it go. closing the window unplugs it.

  • crow: plug it in; it appears like on the device.
  • gamepads / joysticks: USB and Bluetooth controllers work with scripts that support them.
  • keyboard: the Mac keyboard is the norns keyboard (see controls).

9. the AUv3 plugin

the app installs an Audio Unit called norns (a music effect: audio in, audio out, MIDI in). it puts norns into a DAW track: the track's audio goes into norns, and norns' output comes back into the track.

  1. start norns.app (the plugin talks to it; norns keeps running in its own window).
  2. in your DAW, insert norns on a track — in Logic as an Audio FX or MIDI-controlled effect, in Ableton Live / Bitwig / Reaper from the Audio Unit plugins.
  3. press play. the plugin window shows connected. while the DAW plays through the plugin, norns hears the track instead of your audio interface and plays into the track instead of your speakers. when the DAW stops, norns goes back to the interface.
  4. MIDI sent to the plugin track reaches norns as the MIDI device norns AUv3 (choose it in a script's MIDI settings or in SYSTEM → DEVICES).

latency: about 8 ms, reported to the DAW so it compensates. norns follows the DAW's clock and sample rate (it resamples internally). use one norns plugin at a time. if norns is not running, the plugin passes audio through unchanged.

if the plugin does not show up: start norns.app once from Applications, then rescan plugins in the DAW (Logic: Plug-in Manager → Reset & Rescan).

"norns cannot be opened"right-click → Open, or Privacy & Security → Open Anyway (see installing).
SUPERCOLLIDER FAIL on the first startmacOS was still checking the bundled libraries; quit and start norns again.
no soundcheck the default output in System Settings → Sound, the levels in the MIX menu, and jackd.log.

maiden does not loaduse http://127.0.0.1:5000/maiden (not localhost), with norns running.

12. differences from the device

  • SYSTEM shows DEVICES, AUDIO, MODS, RESET and RESTART. Wi-Fi and the password are the Mac's job, scripts are updated in maiden, and norns itself with a new version of the app.
  • the encoders are endless: E1 goes round the menu pages (after PARAMS comes MIX again). inside a page and in scripts, values stop where the page or script lets them stop.
  • SYSTEM → RESTART restarts norns and SuperCollider; SLEEP quits norns (it does not put the Mac to sleep).
  • no battery or screen settings: there is no battery, and the screen is a window.
  • audio device and sample rate come from macOS (see audio).
  • maiden and the consoles are local-only (127.0.0.1); OSC (port 10111) is reachable on your network, so phone controllers like TouchOSC work as on the device.

13. uninstalling

delete /Applications/norns.app. your norns folder ~/norns (scripts, audio, data) stays; delete it too if you no longer need it.
